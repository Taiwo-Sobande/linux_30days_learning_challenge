## What I Learned
Linux is an open-source operating system based on the UNIX operating system. It works well across many devices and industries.

The majority of data systems are built on Linux e.g Cloud VMs in Microsoft Azure, Amazon Web Services, Data warehouses, servers, containers etc.

A linux distribution includes the Linux kernel, system libraries, and essential software tools. It provides users with everything needed to run Linux on different types of devices.
Around 600 + Linux Distributions are available and some of the popular Linux distributions include Ubuntu, Debian,Kali Linux, M Linux, Manjaro, Linux Mint, Solus, Fedora etc
